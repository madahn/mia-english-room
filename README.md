# Mia's English Room

유아 영어 회화 연습 앱. 아바타 튜터 미아와 파닉스 → 단어 → 간단한 회화 → 일상회화를 듣고 따라 말하며 배웁니다.

브라우저(Safari/Chrome/Edge)에서 열면 바로 동작하며, 마이크 권한을 허용하면 따라 말하기 인식이 켜집니다.
